# Ошибки 401: истёк токен клиента

**Симптомы.** 401 Unauthorized, invalid_token, «token expired» у одного клиента (например, device-agent), у остальных всё работает.

**Почему так бывает.** Клиент получил токен с ограниченным сроком жизни (ttl), а автоматическое обновление (refresh_token) не настроено.

**Как подтвердить.** В auth-service — отклонённые токены этого клиента с причиной expired; в конфигурации клиента нет refresh_token.

**Что сделать.** Настроить обновление токена до истечения срока; мониторинг доли 401 по клиентам.
