# Сервис не стартует после деплоя: ошибка конфигурации

**Симптомы.** «missing required env var», KeyError на чтении настроек, CrashLoopBackOff, очередь без обработчиков.

**Почему так бывает.** Новая версия требует переменную окружения или секрет, которых нет в конфигурации стенда.

**Как подтвердить.** Логи запуска пода; сравнение ConfigMap/Secret стенда с требованиями новой версии.

**Что сделать.** Добавить переменную в конфигурацию стенда; в CI — проверка обязательных переменных до деплоя.
