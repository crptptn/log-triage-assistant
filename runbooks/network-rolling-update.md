# Обрывы соединений между сервисами при деплое

**Симптомы.** Connection reset by peer, ECONNREFUSED при обращении к сервису, повторный запрос проходит; рядом события rolling update или graceful shutdown.

**Почему так бывает.** Под завершается, а балансировщик ещё шлёт на него трафик: нет readiness-проверки, нет задержки перед остановкой (preStop), клиент не повторяет идемпотентные запросы.

**Как подтвердить.** Время ошибок совпадает с событиями k8s о завершении подов; в логах сервиса — graceful shutdown.

**Что сделать.** readinessProbe, preStop sleep 5–10 с, terminationGracePeriodSeconds, повтор идемпотентных запросов на стороне клиента.
